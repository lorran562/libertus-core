## FUNDAMENTOS

### Criptografia Simétrica
**AES (Advanced Encryption Standard):**
- Block cipher (128-bit blocks)
- Key sizes: 128, 192, 256 bits
- Modos: ECB, CBC, CTR, GCM, CCM

**Implementação Python:**
```python
from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes
from Crypto.Util.Padding import pad, unpad

key = get_random_bytes(32)  # 256-bit
cipher = AES.new(key, AES.MODE_CBC)
ct = cipher.encrypt(pad(plaintext, AES.block_size))
```

**ChaCha20:**
- Stream cipher
- Faster que AES em software
- Mobile-friendly (ARM otimizado)

### Criptografia Assimétrica
**RSA:**
- Key sizes: 2048, 3072, 4096 bits
- Padding: OAEP, PSS
- Uso: Key exchange, digital signatures

**Geração de chaves:**
```python
from Crypto.PublicKey import RSA

key = RSA.generate(4096)
private_key = key.export_key()
public_key = key.publickey().export_key()
```

**ECC (Elliptic Curve Cryptography):**
- Menor tamanho de chave (256-bit ≈ 3072-bit RSA)
- Mais rápido
- Curvas: secp256k1, Curve25519, P-384

**ECDSA (Assinatura Digital):**
```python
from ecdsa import SigningKey, SECP256k1

sk = SigningKey.generate(curve=SECP256k1)
signature = sk.sign(message)
vk = sk.verifying_key
vk.verify(signature, message)
```

## HASHING & DERIVAÇÃO

### Hash Functions
**SHA-256:**
```python
import hashlib

hash_obj = hashlib.sha256()
hash_obj.update(data)
digest = hash_obj.hexdigest()
```

**bcrypt (Password Hashing):**
```python
import bcrypt

hashed = bcrypt.hashpw(password, bcrypt.gensalt(rounds=12))
if bcrypt.checkpw(password, hashed):
    print("Match!")
```

**PBKDF2:**
```python
from hashlib import pbkdf2_hmac

key = pbkdf2_hmac('sha256', password, salt, 100000)
```

### Key Derivation Functions
**Argon2 (Winner of PHC):**
- Memory-hard
- Resistance contra GPU/ASIC
- Tipos: Argon2i, Argon2d, Argon2id

**scrypt:**
```python
from hashlib import scrypt

key = scrypt(password, salt=salt, n=2**14, r=8, p=1)
```

## SSL/TLS

### Handshake Process
1. ClientHello
2. ServerHello + Certificate
3. Key Exchange (ECDHE)
4. ChangeCipherSpec
5. Finished

### TLS 1.3 Improvements
- 0-RTT resumption
- Removed weak ciphers (RC4, 3DES)
- Forward secrecy obrigatório

## ATAQUES E DEFESAS

### Timing Attacks
**Vulnerável:**
```python
def compare(a, b):
    if len(a) != len(b):
        return False
    for x, y in zip(a, b):
        if x != y:
            return False  # Sai cedo!
    return True
```

**Seguro (Constant-time):**
```python
import hmac

def compare_safe(a, b):
    return hmac.compare_digest(a, b)
```

### Padding Oracle Attack
- CVE-2014-0160 (Heartbleed)
- CVE-2016-2107 (Lucky13)
- Mitigação: Authenticated encryption (GCM, CCM)

### Side-Channel Attacks
**Cache timing:**
- Spectre, Meltdown
- Mitigação: Constant-time algorithms

**Power analysis:**
- DPA (Differential Power Analysis)
- Mitigação: Masking, shuffling
